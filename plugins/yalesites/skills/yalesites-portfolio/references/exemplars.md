# Exemplar sites per block (2026-10 review)

Picks come from a screenshot review of the 8 richest usages per block (ranked by instance count and config variety), judged for visual quality, content fit and reusability. Rank 1 is strongest. Anti-patterns name real sites so reviewers can look; treat them as teaching examples, not call-outs.

Adoption is high-usage ≠ well-used: check here before holding a site up as a model.

## Wrapped Image (`wrapped_image`)

1. **jewishstudies** - https://jewishstudies.yale.edu/  
   Large, richly detailed archival images with informative captions that include source links, wrapped beside body text. Alternating sides and a mix of image shapes give the page editorial rhythm, and the images carry meaning rather than decoration. *Pattern: large artwork/archival image with credited caption, alternating left/right, beside 1-2 paragraphs*
2. **wlab** - https://wlab.yale.edu/about  
   Images are paired with a heading and the text wraps neatly beside them. Photos of people in the lab and community show the real work and give each section a clear visual anchor. *Pattern: photo of real lab work beside heading + paragraph, with images alternating sides*
3. **ism** - https://ism.yale.edu/about/facilities-and-resources  
   Strong photos of the actual rooms with short captions, paired with a heading and an offset image. The text length is reasonable and the wrap reads cleanly. *Pattern: facility photo + short caption + heading-led section, offset image style*

**Good practices:** Write captions with credit and links when the image is archival or informational · Alternate image alignment between sections · Keep image width consistent so wrap lines stay stable · Use the image to show the actual subject (people, rooms, artifacts) · Break long text with headings so the wrap does not run for screens · Use the offset style for most uses and floated for tight illustrations

## View (`view`)

1. **planetarysolutions** - https://planetarysolutions.yale.edu/programs  
   Uses the View as a tidy 3-up card grid where each card carries a bold branded graphic, a short title and a one-line teaser, so the program list reads like a designed landing section. The same block is reused for news, a faceted research-project browser (Action Area filter plus pagination) and related resources, showing how flexible one component can be. *Pattern: 3-column card grid + consistent image per item + short teaser, with optional filter and pagination for long collections*
2. **ism** - https://ism.yale.edu/  
   Strong, large, well-cropped photos in an even 3-column grid, titled with a clear section heading. It is used both for Latest News (with dates) and as a section navigation hub (About, Admissions, Choirs, People) with one-sentence descriptions, which is an effective visual wayfinding pattern. *Pattern: 3-up image cards with title and one-sentence teaser as a visual navigation hub*
3. **isps** - https://isps.yale.edu/leadership  
   Profile-card view of people (photo, department eyebrow, name, title, email) in a clean 4-column grid for the Executive Committee, plus a 3x2 image news grid on the homepage. Consistent crops and metadata make it scannable and credible. *Pattern: 4-up profile cards with department eyebrow, name, title and email link*

**Good practices:** Use a clear section heading (Latest News, Upcoming Events) above the view · Keep to 3 or 6 items in a 3-column grid so rows fill evenly · Use consistent image crops and real photography or branded graphics for every item · Show date plus a one-sentence teaser, not full excerpts · Add filters and pagination only when the collection is long · Reuse one view style site-wide for consistent news, events and people lists

## Callout (`callout`)

1. **usability** - https://usability.yale.edu/  
   The two-up callout pairs parallel services (Usability Consulting, Accessibility Consulting) with a short heading, one clear sentence each, and a descriptive button label. Equal-length copy keeps the divider-split layout balanced, and the light-gray single callout and the dark-blue stage-transition callout show the block working as both a pitch and a wayfinding step. *Pattern: two-up callout with parallel headings, one-sentence blurbs, and descriptive button labels on a solid brand-blue band*
2. **poorvucenter** - https://poorvucenter.yale.edu/  
   Short headings with one-line blurbs and a single outlined button in each half; the one-up annual report callout is just a heading and a button, which is a clean, high-contrast closing CTA. External and PDF links carry the arrow/download icon so the destination type is clear. *Pattern: short action heading + one-line blurb + one button, alternating blue and light-gray bands to separate asks*
3. **yalesites** - https://yalesites.yale.edu/continuous-improvement/2026-platform-roadmap  
   Question-style headings (Need Help? Want to Talk Live?) map directly to the buttons below them, and the pair on the roadmap page splits a known-issues path from a feedback path. Copy is brief and the band colors vary by page without hurting contrast. *Pattern: question heading answered by a matching action button, used as a page-closing next-step pair*

**Good practices:** Keep headings under about six words and blurbs to one or two sentences · Use a descriptive button label that names the destination, not just Learn More · Pair two parallel items in the two-up layout and keep their copy lengths similar · Use the external-link arrow on off-site destinations · Use a solid brand color band or a dark-overlay image with white text for contrast · Use a callout as a closing next-step on a page, not mid-paragraph
